# SOC Investigation Evidence

## Overview
This directory contains supporting screenshots collected and organized for the simulated SOC Incident Response & Investigation Case Study, Incident ID `TN-INC-2026-001`.

The evidence illustrates the investigation process and supports the analysis documented in the incident response report.

## Evidence Categories

### 1. Authentication Activity
Screenshots showing relevant login activity, including suspicious or repeated authentication attempts identified during the investigation.

### 2. Endpoint Security Alerts
Screenshots documenting endpoint alerts associated with suspected malware or other potentially malicious activity.

### 3. Network Activity
Screenshots illustrating relevant firewall events or suspicious outbound connections reviewed during the investigation.

### 4. Incident Timeline and Attack Chain
Visual evidence showing the chronological sequence of relevant events and how the findings were correlated to develop a suspected attack scenario.

## Purpose of Evidence
The screenshots help demonstrate:
- Security alert triage and investigation.
- Analysis of authentication and endpoint activity.
- Correlation of network and endpoint events.
- Identification of potentially significant indicators.
- Evidence-based incident documentation.

## Evidence Handling
Screenshots are provided for educational and portfolio demonstration purposes. They should be interpreted alongside the investigation dataset and final report.

Any real credentials, personal information, confidential client data, or other sensitive material must be removed before publication. Evidence should not be altered in a way that misrepresents the original findings.

## Disclaimer
This is a simulated educational case study. The screenshots support the documented investigation but do not independently establish that a real security incident occurred.
