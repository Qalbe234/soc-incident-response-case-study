# SOC Investigation Data

## Overview
This directory contains the structured data used in the simulated SOC incident response investigation for incident `TN-INC-2026-001`.

The dataset supports the analysis of suspicious authentication activity, endpoint security alerts, outbound network connections, and the chronological sequence of events.

## Files

### SOC Investigation Data
The investigation workbook contains the available security event data and supporting analysis.

Depending on the workbook contents, this may include:
- Authentication and login events.
- Endpoint security and malware alerts.
- Firewall and network activity.
- Indicators of Compromise (IOCs).

### Incident Timeline
The timeline workbook organizes relevant events chronologically to help correlate activity across the simulated data sources and reconstruct the suspected attack sequence.

## Investigation Objectives
- Identify suspicious events and patterns.
- Correlate activity across multiple data sources.
- Establish a timeline of relevant events.
- Document indicators requiring further investigation.
- Support incident severity assessment and response recommendations.

## Data Handling
The data is intended for educational and portfolio demonstration purposes. Organization names, user identifiers, IP addresses, domains, and other indicators must be treated according to the dataset's actual provenance. Sensitive or confidential information should be removed before public release.

## Disclaimer
This is a simulated educational investigation. The conclusions depend on the evidence available in the project and should not be interpreted as proof of a real-world compromise.

## Skills Demonstrated
Security log analysis, event correlation, timeline reconstruction, IOC management, and evidence-based investigation.
